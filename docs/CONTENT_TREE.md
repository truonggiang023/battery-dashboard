# Cây nội dung theo yêu cầu

30 function, 110 nội dung con. Chọn Project → Chemistry → Cell Size trước khi mở function. Sidebar giữ phẳng; cây này nằm trong vùng chính.

Mỗi function là một file Excel; mỗi nội dung con là một sheet. Σ là sheet tổng hợp chỉ đọc, tự cập nhật từ dữ liệu gốc; nút cập nhật dẫn tới sheet nhập liệu tương ứng. Các tab nhập liệu kỹ thuật bổ sung được giữ để tính toán và truy vết.
